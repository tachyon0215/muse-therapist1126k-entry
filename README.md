# muse-therapist1126k-entry

Entry for the make.fun competition [Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41).

## The entry

> Diagnosis: you don't have attachment issues - you have 47 open tabs, each one a version of you avoiding one email.

Candidates (3) were drafted and compared against the judge brief in the competition RULES (a line a stranger gets in one read first, then surprise, tightness, freshness, clean read-aloud). Selection reason: Clinical term flipped into a concrete tab image that escalates to the avoided email; B/C are single metaphors.

## How it works

`main.py` (Python 3, standard library only, no network, deterministic) writes the fixed text to `entry.txt`.
