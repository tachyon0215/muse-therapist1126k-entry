Submitted to the make.fun competition [Your AI Therapist's Diagnosis](https://make.fun/bounty/u-motasimfuad-your-ai-therapist-s-diagnosis-4be14a41), which asks for the one-line verdict an AI therapist would deliver.

## The line

> Diagnosis: you don't have attachment issues - you have 47 open tabs, each one a version of you avoiding one email.

## Why this one

Three drafts were put side by side and scored against the RULES brief: a stranger should grasp the joke on a single read, then be surprised by it, with nothing padded and nothing awkward read aloud. The runners-up each relied on one lone metaphor. The winner instead opens with a piece of clinical vocabulary and pivots to a mundane, sharply specific image — a browser stuffed with tabs — that keeps narrowing until it lands on the one email being dodged.

## Running it

Executing `main.py` with Python 3 (standard library only; it never touches the network and has no randomness) writes the fixed line to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR`.
